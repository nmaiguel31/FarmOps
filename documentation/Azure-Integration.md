# Azure Integration

## Overview

FarmOps uses Microsoft Azure as its cloud hosting platform.

## Architecture

Frontend:
https://farmops-blond.vercel.app/

Backend:
https://farmops-api-nmaiguel.azurewebsites.net/

Database:
MongoDB Atlas

## Azure Services Used

- Azure App Service
- Environment Variables
- HTTPS Deployment

## Deployment Flow

User
↓
Vercel Frontend
↓
Azure App Service API
↓
MongoDB Atlas

## Benefits

- Cloud-hosted backend
- Secure HTTPS communication
- Scalable deployment model
- Production-ready architecture
